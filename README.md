# Burl Plate mix library

Public archive of saved mixes for [Burl Plate](https://github.com/JPFava/burl-dist).

**Read:** anyone. In the app, **Browse public library** loads the JSON files in `mixes/`.

**Write:** GitHub does not allow strangers to push to a repo. To add a mix:

1. In Burl Plate, **Export this mix**.
2. Either open a pull request that adds `mixes/your-mix-name.json`, or email/send the file to the maintainer.
3. Once it is on `main`, every shop PC can import it from the library.

Do not put overlay images or STEP files here — mixes are settings only (pattern, color line, sliders, seeds).
